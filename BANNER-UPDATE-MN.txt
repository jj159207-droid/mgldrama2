• Үзэх хугацаа төлбөр баталгаажсан мөчөөс эхэлнэ.

СУУЛГАХ — ЗӨВХӨН ХОЁР ФАЙЛ ХУУЛНА
1. Серверийн өмнөх хар цонхонд Ctrl+C дарж зогсооно.
2. ZIP-ээ бүрэн задлана.
3. Win+E дарж өөр хавтасны цонх нээгээд дараах замд орно:
   D:\New folder (3)\Downloads\mgldrama2-reviewed\mgldrama2-reviewed\app
4. Тэнд байгаа хуучин page.tsx болон globals.css-ийг Desktop дээрх тусдаа нөөц хавтас руу хуулна.
5. Шинэ ZIP-ийн app хавтас доторх page.tsx, globals.css хоёрыг дээрх төслийн app хавтас руу хуулж, Replace the files in the destination гэдгийг сонгоно.
6. Сервер ажиллуулдаг өмнөх хар цонхонд:
   npm run dev -- --hostname 10.255.85.198 --port 3000
7. Ready гарсны дараа компьютер дээр сайтаа Ctrl+F5 дарж шинэчилнэ. Утас дээр хуудсаа дахин ачаална.

Энэ шинэчлэлтэд INSTALL.cmd ажиллуулах, SQL ажиллуулах шаардлагагүй.
Өмнөх SMS-ийн хоцорсон төлбөрийн засвар энэ page.tsx дотор хадгалагдсан.
