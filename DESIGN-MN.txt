MGL DRAMA — Харагдацын шинэчлэлт

Энэ багц зөвхөн дараах 3 файлыг солино:
app/page.tsx
app/globals.css
public/cinema-cover.webp

Суулгах
1. ZIP-ээ тусдаа хавтас руу задлана.
2. Шинэ төслийн зам:
D:\New folder (3)\Downloads\mgldrama2-reviewed\mgldrama2-reviewed
3. Төслийн app/page.tsx, app/globals.css файлуудаа өөр хавтас руу хуулж нөөцөлнө.
4. Задалсан багцын app доторх page.tsx болон globals.css-ийг төслийн app дотор хуулж солино.
5. Багцын public доторх cinema-cover.webp-ийг төслийн public дотор хуулна.
6. npm run dev ажиллаж байгаа үед браузертоо Ctrl + Shift + R дарна.

Хэрэв сервер ажиллаагүй бол төслийн үндсэн хавтсанд cmd нээгээд npm run dev ажиллуулна.
Файлын өргөтгөлийг харуулж, нэр нь page.tsx, globals.css байгаа эсэхийг шалгана.

Өөрчлөлт
- Бараан, алтлаг өнгө бүхий нүүр, кино театрын зураг.
- Босоо киноны постер, зураггүй кинонд гарчигтай нүүр.
- Давтагддаг анивчдаг багцын сурталчилгааг нэг санал болгож цэгцэлсэн.
- Ангилал, хайлт, гар утасны байрлал, товчийн хэмжээ шинэчилсэн.
- Товч үзэхийг тусдаа товчоор нээнэ.
- Багц, нэвтрэлт, төлбөрийн цонх, админы цэсийн харагдац шинэчилсэн.
- Төлбөрийн текст одоогийн баталгаажуулалтын ажиллагааг үнэн зөв тайлбарлана.

Энэ багц өгөгдлийн сан, нууц тохиргоо, API файлуудыг солихгүй.
QPay автомат баталгаажуулалт нэмээгүй. Bunny-ийн үлдэгдэл, видео холбоосын асуудлыг энэ дизайн шийдэхгүй.
Киноны жинхэнэ постерийг админд оруулахад карт дээр автоматаар харагдана.
Өгөгдлийн сангаа хуваалцдаг хуучин сайт дээр энэ харагдац өөрөө нийтлэгдэхгүй.
